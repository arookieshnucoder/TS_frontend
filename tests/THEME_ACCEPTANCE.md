# 学科主题验收

在 `frontend` 中运行：

```sh
node --test --test-timeout=30000 tests/theme-ui.test.mjs tests/demo-chat.test.mjs tests/chat-ui.test.mjs
npm test
npm run build
```

`theme-ui.test.mjs` 挂载真实 Vue 页面，并禁止所有 `fetch` 请求，验证默认演示在离线环境独立工作：

- 三个学科按钮的可访问名称、选中状态，以及语文/数学/英语欢迎内容与输入提示。
- 三学科草稿和历史隔离；切科重置搜索；刷新恢复，包括直接恢复保存的英语主题；题卡发送保留未提交草稿。
- 题卡与演示回答对应；Enter 发送、Shift + Enter 和输入法确认不误发；生成时禁止切科；停止后显示完整回复。
- 浏览器存储不可用时明确提示，并继续在内存中保存当前页面的分科对话。
- 移动端关闭侧栏移出键盘导航，Escape 关闭并恢复展开按钮焦点。
- 鼠标跟随、点击反馈、快速点击数量上限和自动回收；动态切换低动效或触屏偏好；卸载时移除全局及媒体查询监听。
- 英语第三按钮保留原生键盘焦点，生成中三科入口全部禁用，停止后恢复；低动效下立即显示英语解析，触屏保留轻量反馈。

`demo-chat.test.mjs` 独立核验十二张题卡的助手回复，而非只检查用户问题。英语四卡要求答案依次为 C（给弟弟借小说）、C（had left）、A（However）、B（Unwilling or hesitant），同时解释原文、时态或逻辑依据。额外的大写、小写和多空白变体不得改变正确选项，提交的英文大小写与换行保持原样。未识别问题、中文诗词或数学题在英语主题中均须返回英语演示提示，不串到其他 Agent。

原有 `chat-ui.test.mjs` 继续在后端模式模拟 HTTP 成功和断网，验证历史、回复、错误状态及失败后草稿保留。`npm test` 还包含本地模拟模型的后端 HTTP 联调，不需要真实模型 Key。

Happy DOM 不提供真实排版、原生 Tab 导航或最终 CSS 动画渲染。浏览器验收应另行检查三学科在桌面、390px 和 320px 窗口下无横向溢出，三个学科入口与输入框可用；动画背景可见，鼠标皮肤与点击反馈对应主题；触屏目标可点击，键盘焦点清楚；系统低动效偏好关闭背景和交互动画。英语入口与题卡只展示阅读理解、语法选择、完形填空和语境词义，不宣传作文或听力服务。
